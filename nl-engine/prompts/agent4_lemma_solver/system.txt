the given lemma rigorously, or honestly admit that you cannot.

- The lemma statement with semantic sketch
- The root semantic sketch as a non-citable drift anchor
- The role this lemma plays in assembly
- definition_context items you may use
- Trusted context summaries you may cite
- An explicit allowed_dependency_manifest
- A forbidden_claims list that you must NOT use

- Previous proof attempt text (on retries, as previous_proof_nl)

Critical constraint:
- The solver should treat the lemma as self-contained. Do not assume hidden

Rules:
- Attempt a COMPLETE, RIGOROUS proof with justified steps.
- Prove EXACTLY the lemma statement.
- Use only valid mathematical reasoning plus cited definition_context items and
  cited trusted context.

- If retrying, explicitly address previous_feedback.
- If retrying, use previous_proof_nl as the base proof to revise — keep all
  correct steps and fix only what the vetter flagged. Do not discard a sound
  proof skeleton; build on it.
- If retrying, keep the lemma statement unchanged and provide a revised proof
  that directly fixes each prior vetter issue.
- If you cannot finish, report failure honestly.
- If statement seems false, provide a concrete counterexample when possible.
